# המספרה של עלמה וענבל ✂️💇

משחק דפדפן (שעובד גם כאפליקציית אנדרואיד) שבו מטפלים בילדה או בחיית מחמד:
גוזרים לה שיער פרוע, בוחרים תספורת וצבע, תופרים לה בגד לפי דגם וצבע,
ובסוף מדרגים בכוכבים כמה אהבתם את התספורת ואת הבגדים. כל היצירות נשמרות
בגלריה במכשיר.

המשחק בנוי כ-HTML/CSS/JavaScript רגיל (ללא ספריות חיצוניות), עובד לגמרי
אופליין, ותומך בעברית ו-RTL. כל הדמויות מצוירות כ-SVG בקוד, כך שאין צורך
בקבצי תמונה חיצוניים.

## איך משחקים (בדפדפן, במחשב או בטלפון)

צריך רק שרת סטטי פשוט (כי הקבצים נטענים כמודולים, ולא ניתן פשוט לפתוח
`index.html` ישירות מהדיסק בכל דפדפן):

```bash
npx http-server www -p 8080 -c-1
# או: npm start
```

ואז לפתוח בדפדפן: `http://localhost:8080`

מבנה המשחק:
1. בוחרים איזו לקוחה מגיעה (ילדה, חתולה, כלבלב או ארנבת).
2. גוזרים את כל השערות הפרועות (מיני-משחק).
3. בוחרים תספורת וצבע שיער.
4. תופרים בגד לפי סדר הנקודות (מיני-משחק תפירה).
5. בוחרים דגם, צבע והדפס לבגד.
6. מדרגים את התספורת ואת הבגדים בכוכבים, ושומרים לגלריה.

## התקנה כאפליקציה בטלפון בלי בנייה (PWA)

הדרך המהירה ביותר לקבל את המשחק כ"אפליקציה" על מסך הבית באנדרואיד, בלי
להתקין שום דבר:

1. מעלים את תיקיית `www` לאירוח סטטי כלשהו (GitHub Pages, Netlify, Vercel
   וכו'), או מריצים אותה על שרת ברשת הבית.
2. פותחים את הכתובת בכרום באנדרואיד.
3. תפריט ⋮ ← "הוספה למסך הבית". המשחק ייפתח במסך מלא עם אייקון משלו,
   ויעבוד גם ללא אינטרנט (יש Service Worker שמטמין את כל הקבצים).

## בניית קובץ APK אמיתי (Capacitor + Android Studio)

כדי לקבל APK/AAB אמיתי שמתקינים כאפליקציה רגילה (או מעלים ל-Google Play),
המשחק כבר מוכן לעטיפה עם [Capacitor](https://capacitorjs.com). התהליך
דורש מחשב עם Android Studio מותקן (יש בו את כל ה-Android SDK הנדרש):

```bash
# 1. התקנת התלויות
npm install

# 2. יצירת פרויקט האנדרואיד (פעם ראשונה בלבד)
npm run cap:add:android

# 3. סנכרון קבצי המשחק לפרויקט האנדרואיד (בכל פעם שמשנים משהו ב-www)
npm run cap:sync

# 4. פתיחת הפרויקט ב-Android Studio לבנייה/הרצה/ייצוא APK
npm run cap:open:android
```

בתוך Android Studio: `Build → Build Bundle(s) / APK(s) → Build APK(s)`
כדי לקבל קובץ APK להתקנה ישירה, או `Build → Generate Signed Bundle / APK`
כדי לפרסם ל-Google Play.

> שימו לב: תיקיות `android/` ו-`ios/` שנוצרות ע"י Capacitor לא נכללות
> בריפו (ראו `.gitignore`) - הן נוצרות מקומית אצל מי שבונה את האפליקציה.

## מבנה הפרויקט

```
www/                    כל קוד המשחק (זה מה ש-Capacitor עוטף לאפליקציה)
  index.html
  styles.css
  manifest.webmanifest   מניפסט PWA
  service-worker.js      תמיכה אופליין
  js/
    characters.js         ציור הדמויות, התספורות והבגדים כ-SVG
    audio.js               אפקטי קול (נוצרים בקוד, בלי קבצי אודיו)

    game.js                  לוגיקת המשחק ומסכים
capacitor.config.json   הגדרות העטיפה לאפליקציית אנדרואיד/iOS
package.json
```
